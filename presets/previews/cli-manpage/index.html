pebble(1)

tiny task runner for tiny projects

Name

pebble — run named tasks from a single plain text file.

Synopsis

pebble [-n] [-f FILE] run TASK...

Description

pebble reads a file named Pebblefile, finds the tasks you ask for and runs them in order. It has no plugins and no config language beyond one line per step.

Commands

  • pebble init

    Create a starter Pebblefile in the current directory.

  • pebble run TASK

    Run one or more tasks in the order given.

  • pebble list

    Print the tasks found in the file.

Options

-f, --file FILE
Read tasks from FILE instead of Pebblefile.
-n, --dry-run
Print what would run and change nothing.
-q, --quiet
Suppress task output except errors.
--version
Print the version (sample: 0.9.0-demo).

Examples

$ pebble init
$ pebble -n run build test
$ pebble run build
Exit status

0 on success, 1 when a task fails, 2 for usage errors (sample values).
