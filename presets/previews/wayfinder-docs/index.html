Wayfinder handbook

A clear path from files to a website.

This sample handbook explains a small static site. It is a usable documentation layout, not a downloadable software product.

Start with the files
No build step required.

This template is plain HTML, CSS and JavaScript. Open it locally or serve it from any static host.

Getting started

Create a folder for your site and put an index.html file at its root. Open the file in a browser to check the page before publishing.

  • Use your own site name and page description.
  • Replace sample writing with verified, useful content.
  • Keep image files in a local assets folder.
Why start with a local preview?

It lets you check text, keyboard navigation and mobile layout before changing a public website. A local preview is not a live deployment.

Keep the structure small

This is an example structure, not a set of generated downloads. Use relative paths so links also work beneath a repository subpath.

my-site/
  index.html
  .nojekyll
  assets/
    coastal-study.webp

For example, an image inside the assets directory can be referenced as assets/coastal-study.webp. Avoid paths beginning with a slash for repository-hosted pages.

Publishing on GitHub Pages

Place your static files in the selected publishing source of your repository. Include an empty .nojekyll file when publishing these plain files from a branch.

Configure Pages in the repository settings, then verify the live address that GitHub reports. This demo does not publish anything or claim that a deployment exists.

Before you share it

Open the live repository-subpath URL. Follow each navigation link, check every image, and use the page with a keyboard.

Troubleshooting

An image works locally but not online

Check filename capitalization and the relative path. Hosting is often case-sensitive even when your local filesystem is not. Verify the image is included in the published folder.

The page is wider than the phone screen

Look for fixed-width content, wide code blocks or images without a max-width rule. This template wraps code and reflows navigation to avoid horizontal page scrolling.

Search shows no results

Search checks the section titles and visible writing on this page only. Try a shorter word or clear the field to show all sections again.
