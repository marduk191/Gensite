Overview

Each row is one short note written by a volunteer surveyor on a shoreline walk, with structured tags added by a second reviewer. The collection is intended for classification, retrieval and summarisation experiments on small, noisy text.

Collection and ethics

How it was made

  • Volunteers wrote notes with consent for open release
  • Names and precise coordinates were removed
  • Two reviewers checked tags; disagreements were dropped

Known gaps

  • Sites cluster near towns with active volunteers
  • Winter months are under-sampled
  • Not suitable for population estimates
