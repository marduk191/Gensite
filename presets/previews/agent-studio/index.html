One run, step by step

Sample trace, invented for the demo.

  1. Plan

    Splits the request into search, read and write, and lists the tools it intends to use before it starts.

  2. Search

    Calls search_docs with a narrow scope instead of loading everything.

  3. Read

    Opens only the two matching files. Each read is logged with its path.

  4. Draft

    Writes a summary that cites the files. It cannot save anything without approval.

  5. Hand back

    Reports what it did, what it skipped and what it is unsure of.

What it can do

Six sample capabilities.

Search

Finds the right file before it reads anything.

Read

Opens documents and records which lines it used.

Draft

Writes proposals as drafts, never as final edits.

Run

Executes allow-listed commands in a sandbox.

Analyse

Turns a table into a short, checkable chart.

Ask first

Pauses for approval before any irreversible step.

Guardrails by default

It will

  • Show each tool call and its result
  • Stop and ask before writing or running
  • Say what it did not check

It will not

  • Act outside the folders you grant
  • Hide failed steps from the log
  • Claim certainty it does not have
